# Mutaher Affan — Portfolio Website

A modern, SEO-optimized portfolio website for **Mutaher Affan**, Senior Software Engineer specializing in FinTech, Digital Payments, and Backend Engineering.

## 🚀 Tech Stack

- **HTML5** — Semantic markup with full SEO optimization
- **CSS3** — Custom properties, animations, responsive design
- **JavaScript (ES6+)** — Vanilla JS, no dependencies
- **Font Awesome** — Icons
- **Google Fonts** — Inter + Fira Code

## 📁 Project Structure

```
portfolio/
├── index.html          # Main HTML with SEO meta tags & Schema.org
├── css/
│   └── style.css       # Complete stylesheet (~950+ lines)
├── js/
│   └── main.js         # Animations, typing effect, interactivity
├── assets/             # Images & media (add your photo here)
├── sitemap.xml         # SEO sitemap
├── robots.txt          # Crawler directives
└── README.md           # This file
```

## 🎯 SEO Features

- ✅ Meta tags (title, description, keywords, author)
- ✅ Open Graph tags (Facebook, LinkedIn sharing)
- ✅ Twitter Card tags
- ✅ Schema.org JSON-LD structured data
- ✅ Semantic HTML5 elements
- ✅ Canonical URL
- ✅ XML Sitemap
- ✅ robots.txt
- ✅ Fast-loading (no heavy frameworks)
- ✅ Mobile responsive
- ✅ Accessible (ARIA labels, skip navigation)

## 🛠️ Deployment

### Option 1: Vercel (Recommended)
```bash
npm i -g vercel
vercel
```

### Option 2: Netlify
Drag & drop the `portfolio` folder to [netlify.com/drop](https://app.netlify.com/drop)

### Option 3: GitHub Pages
Push to a GitHub repo and enable Pages in Settings.

## 📝 Customization

1. Replace placeholder profile image with your actual photo in `assets/`
2. Update the Formspree form action URL in `index.html`
3. Update canonical URL and OG URLs to your actual domain
4. Add your actual favicon files
