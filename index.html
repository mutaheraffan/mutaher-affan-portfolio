About Me

I'm a Software Engineer focused on backend development, APIs, digital payments, and financial technology — building reliable microservices and middleware that banks, fintechs, and payment platforms can trust.

I work primarily with Java (Spring Boot, Quarkus) and Python (Django), developing secure REST APIs, scalable microservices, and integration layers. I also work with Docker and modern observability tools including ELK, Prometheus, and Grafana to build and maintain production-ready systems.

At Paysys Labs, I contributed to large-scale digital banking and payment platforms, including projects involving NBP, CDNS, and PayVay PSO. My work included architecting integration layers, modernizing legacy authentication services, improving API performance, and strengthening application security using Spring Security.

I successfully completed the EthSwitch project during an onsite deployment in Ethiopia, working on integrating the Instant Payment System (IPS) with local payment rails using ISO 20022 PACS messages for P2P and P2M transactions.

Currently, I'm working at Systems Limited as Consultant – App Development, engaged with CelcomDigi, a leading Malaysian telecommunications and digital services company.
